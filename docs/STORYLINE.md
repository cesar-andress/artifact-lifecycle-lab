# Storyline — Late Binding in Machine-Consumed Instruction Files

**Central idea:** Machine-consumed instruction files are late-binding artifacts whose static referential integrity and runtime agent impact are different phenomena—agents strongly consume instructions, but task success is gated by environment and load-bearingness, not by whether pointers were true at commit time.

---

## Act I — Current belief

The field treats AGENTS.md, skills manifests, and IDE rule packs as a new kind of project documentation whose main engineering risk is **truth decay**: references that were correct when written gradually become wrong as the repository moves, and those stale pointers mislead coding agents at task time. Under this view, longitudinal panels that mark references VERIFIED or MISSING at each commit measure the same failure mode practitioners care about, born-stale and post-verification decay are often folded into one “staleness” rate, and the operational worry is that **false referential content reliably degrades agent outcomes**—so keeping instruction files synchronized with the repo is both the integrity problem and the remedy.

## Act II — Why that belief motivated this work

That belief motivates a natural research program: first map how referential truth evolves in machine-consumed files over repository history, then ask whether observed rot imposes **measurable operational cost** when agents actually run. The work therefore builds a longitudinal corpus (RQ1–RQ4), separates born-stale from post-verification decay, audits suspicious labels, validates whether agents truly maintain these files (P4), and runs a controlled experiment (RQ5) that swaps truthful versus confirmed-false instruction content at a pinned commit while holding the workspace and test command fixed—with a no-instruction arm added to distinguish file presence from referential truth. The implicit promise is that if truth decay is real and harmful, static panel findings should connect to causal differences in agent success.

## Act III — Evidence contradicting the belief

The frozen evidence breaks the simple decay-and-harm story on three axes. **Static integrity:** genuine post-verification decay is effectively absent in the audited cohort (0/121 adjusted failures; most flagged transitions are extractor artifacts), while the dominant static problem is references **already false at creation** (1200/1405 confirmed in GFC audit), born from heterogeneous mechanisms rather than time-based rot. **Runtime behavior:** when instruction files are present under protocol, agents read them universally (128/128) and frequently act on anchor references even when they are confirmed false (77.8% on condition B), expanding edit scope dramatically (~100 vs ~2 files modified vs no-instruction)—so instructions are executive, not ignored. **Causal impact:** swapping truthful for false referential content does not change task success on paired triplets (Δ A−B = 0.00 pp; McNemar p = 1.0); failures concentrate in test execution under hard tasks, not compilation, and wide confidence intervals cannot support claims that truthfulness reliably helps or falsehood reliably hurts.

## Act IV — New conceptual model

The **late-binding model** replaces the single “documentation truth” frame with two coupled channels and two time scales. The **directive channel** (norms, policies, workflow text) shapes agent goals and edit scope whether or not a pointer resolves. The **referential channel** (paths, commands, configs) carries claims whose **static truth** is assessed at commit time in observational panels but whose **runtime resolution** happens only when an agent consumes the file against the live workspace. Outcomes therefore depend on environmental task difficulty and on whether a reference is **causally load-bearing** on the task path—not on static VERIFIED/MISSING labels alone. Selection effects (cited paths disproportionately stable vs matched controls) further explain why many false references can coexist with weak success differentiation: instruction files often cite peripheral, low-churn artifacts while agents still follow them.

## Act V — Implications

The central implication for software engineering measurement is to **stop collapsing constructs**: observational **Truth Decay** (static panel integrity, born-false prevalence, rare post-verification decay) must be reported separately from conditional **Truth Debt** (downstream agent harm)—and the current causal pilot does not justify promoting Truth Debt from null A−B results. For practice and tooling, instruction files should be managed as **two-channel specifications**: lint referential pointers at consumption time, not only at commit time; mark load-bearing vs contextual references; instrument read–repair telemetry; and control edit blast radius when directive-rich files enter context, since presence alone can inflate scope without improving success. Agent-maintenance attribution (validated in P4) remains a distinct observational signal: agents do change these files, but that maintenance is not evidence that static truth drives task outcomes in the RQ5 design.

## Act VI — Future research

Open work follows directly from what the frozen program could not establish. **Complete** the aligned A/B/C factorial on all cases with a unified ledger and pre-registered primary analysis on load-bearing strata, so presence, directive content, and referential truth are not confounded. **Replicate** across agent platforms and consumption settings (CLI vs IDE, optional vs injected files) before generalizing uptake or null causal findings. **Validate** trace-derived constructs (instruction followed, load-bearing, false-claim harm) against human-coded trajectories and semantic falsehood labels, not only mechanical MISSING states. **Extend** comparisons beyond machine instruction files to human-facing docs under the same pinned tasks. Until then, the defensible claim is narrow but important: machine-consumed instruction files bind at runtime through directive and referential channels, static integrity problems are mostly born-false rather than decay-driven in this cohort, and referential static truth—by itself—is a poor predictor of agent task success under the environmental difficulty captured here.
