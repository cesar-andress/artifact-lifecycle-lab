## Title recommendation — KEEP

**Keep:** *Late Binding in Machine-Consumed Instruction Files*

**Justification:** The title names a measurement distinction (authoring-time static integrity vs runtime resolution when agents consume instruction files). That distinction remains appropriate for:

1. the observational track (RQ1–RQ4 + audits), which shows static misalignment is chiefly birth-time / classification rather than verified-then-missing rot; and  
2. an exploratory agent pilot showing high read/follow and presence-driven edit scope coexisting with a null paired A−B success contrast under stated limits.

The title does **not** require confirmatory proof of Truth Debt, human-validated load-bearing, or a completed causal theory.  
**Do not auto-change the title.** A born-stale-only retitle (as sketched in `TOSEM_READINESS.md`) remains an optional strategic alternative for a narrower submission, not a necessary consequence of this audit.
