# Release notes — v1.0.0

**Title:** Artifact Lifecycle Lab — TOSEM replication package v1.0.0  
**Date:** 2026-07-31  
**Tag:** `v1.0.0`

## Summary

First archival release of the replication package accompanying the manuscript
*Measuring Mechanical Reference Integrity in Machine-Consumed Instruction Files*
(ACM TOSEM submission).

## Highlights

- Frozen observational exports (RQ1–RQ4), confirmatory audits, and exploratory RQ5 ledgers.
- Authoritative claim inventory and 28-row claim-to-evidence table.
- Makefile targets for optional observational regeneration.
- Explicit non-distribution of withdrawn load-bearing annotation kits.
- MIT license, CITATION.cff, and Zenodo metadata template.
