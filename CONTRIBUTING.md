# Contributing

This repository is released as an **archival replication package** for a frozen
TOSEM manuscript (science freeze 2026-07-03).

- Do **not** modify frozen exports under `exports/` to “improve” manuscript numbers.
- Do **not** redistribute withdrawn annotation kits under `exports/rq5_lb_blind_annotation/`.
- New analyses belong in a fork or a post-camera-ready branch, not in tag `v1.0.0`.

For verification workflows, see [REPLICATION.md](REPLICATION.md).
