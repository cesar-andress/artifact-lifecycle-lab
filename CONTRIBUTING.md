# Contributing

This repository is released as an **archival replication package** for the
Empirical Software Engineering (EMSE) manuscript
*Measuring Reference Integrity in Coding-Agent Instruction Files: An Audited Longitudinal Study*
(science freeze 2026-07-03; package version **1.2.1**).

- Do **not** modify frozen exports under `exports/` to “improve” manuscript numbers.
- Do **not** redistribute withdrawn annotation kits under `exports/rq5_lb_blind_annotation/`.
- New analyses belong in a fork or a post-camera-ready branch, not in tag `v1.2.1`.

For verification workflows, see [REPLICATION.md](REPLICATION.md).
