## Summary

Version **1.2.0** is a packaging, documentation, and metadata release for the EMSE manuscript.

It:

- aligns public metadata and documentation with the EMSE manuscript;
- improves organization and reproducibility documentation where needed;
- preserves the frozen scientific evidence;
- does **not** change the study's frozen observational data, human labels, protocols, or scientific results;
- supersedes **v1.1.0** as the recommended package version for readers of the EMSE manuscript.

Prior versions remain available for provenance. v1.1.0 and v1.0.0 are not deleted or rewritten.

## What did not change

- Frozen observational exports under `exports/`
- Independent human audit labels and audit decisions
- Frozen protocols and claim-to-evidence mappings
- Scientific numerators and denominators used by the manuscript
- Science freeze date for primary manuscript numbers: **2026-07-03**
