# WITHDRAWN — not a distribution target

The RQ5 v1/v2 material-necessity (load-bearing) human annotation kits are
**withdrawn** and must **not** be distributed or used.

A construct-validity feasibility audit concluded that the frozen RQ5 task
definitions are instruction-coupled and lack an independent task oracle, so
necessity judgments would be circular.

- Annotation packets and rater kits previously under this directory were removed
  from the archival tree for release `v1.0.0`.
- See also `DO_NOT_DISTRIBUTE_V2.md` and the manuscript threats discussion
  (material-necessity annotation not executed / not distributed).
- Do not run `make rq5-v1-blind-lb-annotation-kit` (blocked).

Feasibility notes may remain for provenance; they are not manuscript evidence.
